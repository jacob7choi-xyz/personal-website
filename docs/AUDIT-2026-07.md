# Codebase audit, July 2026

Canonical record of the audit and its remediation. This file is the authority on
what was found and how it was closed. Earlier conversational summaries disagreed
about whether there were 12 or 13 findings; **there are 13**, A-01 through A-13,
and every closing commit below is an ancestor of `main`.

Scope: correctness, accessibility, dependency security, CI and documentation.
Conducted 2026-07-29, remediation completed 2026-07-30.

## Controls introduced during remediation

These are durable, not one-time fixes, and all run in protected CI on Node 24:

| Control | What it prevents |
|---|---|
| `npm run audit:check` | A dependency advisory shipping without a dated, expiring, reviewed exception. Fails closed on unreachable registry, malformed output or unrecognised schema. |
| `npm run audit:test` | The advisory gate itself failing open. |
| `npm run verify:signature` | The committed signature drifting from what the font, `opentype.js` and generator actually produce. |
| `npm run verify:provenance` | A committed asset being swapped without a visible edit to its recorded hash. |
| `npm run validate:content` | Invalid annotated prose reaching the repository, independently of whether anything renders it. |
| `npm run test:annotations` | The annotated-text compiler failing open on malformed input. |
| `npm run verify` | The above drifting apart locally; one fail-closed chain. |
| Branch protection on `main` | Any of the above being bypassed on the way to production. |

## Deliberately not done

- **Two commit messages in published history** reference the internal conventions
  file, and one merge commit contains an em-dash. Fixing means rewriting history on
  `main` for a cosmetic rule. Accepted debt.
- **No ADR for the current single-page design.** The decision record stops at the
  slideshow era. Writing ADR-003 requires the owner's design rationale.
- **Repository-wide binary discovery** for the provenance lock. It covers the assets
  listed in `scripts/asset-provenance.json`; explicit registration is clearer for
  two files.
